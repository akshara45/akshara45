## 🚀 Featured Project

### AccessAdapt — Adaptive Web Accessibility Extension

AccessAdapt is a personalized browser extension designed to make websites more accessible based on individual user preferences.

It analyzes webpages for accessibility issues and provides personalized recommendations based on the user's accessibility profile.

**Key features:**
- Personalized accessibility profiles
- First-launch onboarding
- Persistent user preferences
- Accessibility issue scanning
- Personalized smart recommendations
- Adjustable text size and spacing
- High contrast support
- Reduced motion
- Focus highlighting

**Technologies:**  
React • JavaScript • Vite • Chrome Extension • Manifest V3 • Chrome Storage API
